# 牌局 · 设备模拟器 1.0

2.8英寸 TCG 设备的软件交互演示，包含游戏王、符文战场、宝可梦三种模式。

本仓库为静态发布文件。GitHub Pages 设置：Deploy from a branch → main → /(root)。
入口为 index.html；不需要安装依赖或运行服务器端程序。

数据与录音保存在访问者自己的浏览器中，不上传到 GitHub。不同域名的浏览器存储独立；从原站点迁移时，请先在“电脑管理 · 记录与备份”导出，再到新站导入。
录音需要浏览器支持并允许麦克风，浏览器清理数据可能导致记录丢失。

素材来源和许可说明见 ASSET_SOURCES.md、fonts/OFL.txt 及 art/dueltools/sources.json。
